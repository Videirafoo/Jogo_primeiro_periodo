# Jogo de Adivinhação em Python

Pequeno projeto didático para quem está começando em programação e quer praticar conceitos fundamentais de Python em um sistema completo e executável.

## O que este projeto ensina

- variáveis;
- funções;
- `if`, `elif` e `else`;
- laços `while`;
- tratamento de erros com `try/except`;
- validação de entrada;
- geração de números aleatórios;
- organização do fluxo com `main()`;
- repetição de partidas.

## Como funciona

O computador escolhe um número aleatório entre **1 e 100**. O jogador informa palpites e recebe dicas dizendo se o número secreto é maior ou menor.

Ao acertar, o programa mostra a quantidade de tentativas e pergunta se o usuário deseja jogar novamente.

## Executar

No terminal:

```bash
python main.py
```
